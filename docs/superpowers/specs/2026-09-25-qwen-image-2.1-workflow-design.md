# Qwen-Image-2.1 本地测试工作流与智能提示词扩写系统设计

## 1. 概述与目标

随着阿里通义开源 Qwen-Image-2.1（7B 单流 DiT 架构），图像生成与编辑能力迎来了原生 2K 分辨率、原生 RGBA 透明通道输出及 Qwen3-VL 文本理解加持。

本项目旨在 `/Users/frank/wk/github/ai/ComfyUI/qwen_image_2.1/` 目录下构建一套完整的本地化测试与运行方案，实现以下核心目标：
1. **极简输入与智能扩写**：用户仅输入一句极简描述（如“雨夜小巷里的机甲猫”），系统利用本地已启动的 LM Studio 大模型服务（端口 1234）自动扩写为适配 Qwen3-VL 文本编码器的结构化、高质量生图 Prompt。
2. **双模式交互**：
   - **自动化命令行套件**：提供一键执行脚本，实现健康检查、提示词扩写、ComfyUI API 调用、图像抓取与耗时评测。
   - **ComfyUI 画布与扩展节点**：提供标准可导入的 Web 画布工作流 JSON，并提供轻量级 `LMStudioPromptExpander` 节点，支持在 ComfyUI 画布内直接一键扩写并流转至采样。
3. **软硬件架构适配**：全面适配 Apple Silicon / Mac Studio 本地推理环境，优先支持 GGUF（Q8_0 / Q4_K_M）与官方 safetensors 双通道无缝切换。

## 3. 核心组件详细设计

### 3.1 提示词智能扩写引擎 (`prompt_expander.py`)

- **职责**：与本地 LM Studio（`http://127.0.0.1:1234/v1`）进行通信，将简短的自然语言转换为富含视觉细节、空间关系和光影质感的提示词。
- **核心功能**：
  1. **服务健康与模型自动侦测**：请求 `/v1/models`，自动获取当前 LM Studio 加载的主力模型（如 `gemma-4` 或 `qwen3.8` 系列）。
  2. **多风格预设注入**：支持 `cinematic`（电影级质感）、`photorealistic`（写实摄影）、`anime`（二次元插画）、`cyberpunk`（赛博朋克）与 `general`（通用高精度）。
  3. **输出规格**：返回规范的 JSON 结构，包含：
     - `positive_prompt`: 结构化英文提示词（主体特征、环境氛围、光影色调、相机景深）；
     - `negative_prompt`: 针对性负向抑制词（肢体残缺、模糊变形、文字噪点等）；
     - `aspect_ratio`: 根据场景推荐的分辨率长宽比（1:1、16:9、9:16、3:4 等）。
  4. **降级与防崩溃机制**：当 LM Studio 未启动或响应超时时，自动回退到内置的规则模板扩写引擎，保证工作流不中断。

### 3.2 命令行端到端测试套件 (`qwen_image21_test.py`)

- **职责**：提供独立的单文件命令行测试入口，负责任务全流程生命周期管理。
- **调用方式**：
  ```bash
  python qwen_image21_test.py --desc "雨夜小巷里的机甲猫" --style cinematic --steps 24 --seed 42
  ```
- **执行流程**：
  1. **依赖项自检**：检测 LM Studio 端口 1234 与 ComfyUI 端口 8188 连通性，检测模型路径是否具备基础权重。
  2. **提示词扩写**：调用 `prompt_expander.py`，并在控制台高亮输出原始输入与扩写后提示词对比。
  3. **工作流注入**：读取 `workflows/qwen_image_2.1_api.json`，动态替换其中的 Positive Prompt、Negative Prompt、Seed、Steps 与分辨率。
  4. **API 推送与监听**：通过 `POST /prompt` 推送任务，通过 WebSocket 监听节点执行进度与耗时。
  5. **结果收集与报表**：自动从 ComfyUI 获取最终生成的图像，保存到 `output/` 目录，并输出详细指标（扩写耗时、生成耗时、显存/内存状态）。

### 3.3 ComfyUI 画布与自定义扩写节点 (`custom_nodes/ComfyUI-LMStudio-Prompt`)

- **节点名称**：`LMStudioPromptExpander`
- **节点分类**：`QwenImage/Prompt`
- **输入参数**：
  - `user_short_desc` (STRING, multiline): 用户输入的简述。
  - `style_preset` (COMBO): `["cinematic", "photorealistic", "anime", "cyberpunk", "general"]`。
  - `lmstudio_host` (STRING, default: "127.0.0.1:1234")。
  - `temperature` (FLOAT, default: 0.7, min: 0.1, max: 1.5)。
- **输出参数**：
  - `positive_prompt` (STRING): 扩写后的正向提示词，直接连入 `CLIPTextEncode`。
  - `negative_prompt` (STRING): 负向提示词。
  - `width` (INT): 推荐宽度。
  - `height` (INT): 推荐高度。

### 3.4 Qwen-Image-2.1 工作流结构 (`workflows/`)

基于 Comfy-Org 官方 Qwen-Image-2.1 规范配置：
- **模型加载器**：`UnetLoaderGGUF` 加载 `qwen_image_2.1-Q8_0.gguf` 或 `UNETLoader` 加载 `qwen_image_2.1_int8_convrot.safetensors`。
- **文本编码器**：`CLIPLoaderGGUF`（type 设置为 `qwen_image`）加载 `Qwen3VL-8B-Instruct-Q4_K_M.gguf`。
- **VAE 加载器**：`VAELoader` 加载专用 `qwen_image_2.1_vae_bf16.safetensors`。
- **采样器参数**：
  - Sampler: `euler`
  - Scheduler: `flow_match` / `simple`
  - Steps: `24`
  - CFG: `4.0`
  - Latent 分辨率：`1024x1024`

## 4. 错误处理与健壮性保障

1. **接口连接容错**：LM Studio 连接失败自动降级至本地规则增强；ComfyUI 无法连通时给出明确的操作提示与启动命令建议。
2. **代码质量保证**：
   - Python 代码单文件控制在 500 行以内；
   - 杜绝 `any` 类型，全部采用 `typing` 注解；
   - 关键函数具备清晰 Docstring 说明用途、入参和返回值；
   - 统一使用语义化变量命名，异常捕获必须附带日志输出与明确提示。

## 5. 验收标准与测试流程

1. **扩写单元测试**：运行 `prompt_expander.py`，传入“一只橘猫”，能在 1-2 秒内通过 LM Studio 输出高质量细节扩写；在关闭 LM Studio 模拟故障时，能优雅回退。
2. **API 工作流验证**：`workflows/qwen_image_2.1_api.json` 能够成功被 ComfyUI 原生 API 解析并执行无报错。
3. **端到端集成测试**：在终端执行 `qwen_image21_test.py` 成功在 `output/` 产出图像及完整计时日志。
4. **画布载入验证**：将 `workflows/qwen_image_2.1_t2i_canvas.json` 拖入 ComfyUI Web 界面能够正常呈现各节点及其连线关系。
