# omp 核心专家角色矩阵 (Recommended Agents)

`omp` 原生支持多智能体并发调度（`task` 工具机制与 subagent 路由），并在 `~/.omp/agent/agents/` 或 `./.omp/agents/` 中管理专职角色定义。

---

## 1. 核心专家角色全景图

| 角色标识 | 角色名称 | 核心职责 | 推荐模型分级 |
| :--- | :--- | :--- | :--- |
| `scout` | 侦查员 | 只读轻量化探索、全库模式搜寻、跨文件依赖拓扑压缩提取 | `smol` (极速/高吞吐) |
| `reviewer` | 代码审查官 | 架构规范校验、代码坏味道排查、并发与边界缺陷预警 | `slow` (高推理深度) |
| `security-reviewer` | 安全专家 | 凭据泄漏、未授权访问、注入攻击、序列化漏洞扫描 | `slow` (高推理深度) |
| `architect` | 首席架构师 | 顶层模块拆解、设计模式选型、系统重构路线图制定 | `plan` (长窗口架构模型) |
| `sonic` | 极速搬砖工 | 纯机械式批量改名、多文件类型替换、重复样板代码消除 | `smol` (极速模型) |
| `task` | 全能执行者 | 默认通用智能体，具备完整执行、编译与自愈验证能力 | `default` (平衡模型) |

---

## 2. 导出与初始化角色

`omp` 支持一键解包官方内置的专家角色到本地目录：

```bash
# 解包至全局配置 (~/.omp/agent/agents/)
omp agents unpack

# 解包至当前工程目录 (./.omp/agents/)
omp agents unpack --project
```

解包后，可直接在各角色 `.md` 文件中按需调整提示词（System Prompt）和工具限制。

---

## 3. 并发 Sub-Agent 调用规范

在 `task` 工具调用时，系统会自动根据任务性质选择最佳角色：

```text
                      [主控 Agent]
                           │
       ┌───────────────────┼───────────────────┐
       ▼                   ▼                   ▼
   [scout]            [reviewer]            [sonic]
 (快速探索结构)       (安全/缺陷校验)      (批量机械替换)
```

- **只读研究任务**：优先分发给 `scout`，避免主会话上下文被海量原始文件污染。
- **重型批量修改**：分解为独立子任务后并行派发给 `task` 或 `sonic` 执行，随后统一回归验证。
